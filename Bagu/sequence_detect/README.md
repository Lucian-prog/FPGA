## 课程 + 手撕沉淀的关键点

1. **三段式结构**（本份代码的骨架）：
   - 第一段时序：只干 "current ← next" 一件事，同步复位；
   - 第二段组合：次态译码，`case` 前先写默认自保持 `next_state = current_state`，**防锁存器**；
   - 第三段输出：Moore 型，只看 `current_state`，输出无毛刺（代价是比 Mealy 晚一拍）。
2. **one-hot 编码**：6 状态 6 bit，译码快、FPGA 友好；`default` 兜底非法编码恢复 IDLE。
3. **重叠检测 = 转移时"往后看后缀"**，本设计三处关键转移：
   - S3 收 0 → S2：`1010` 后缀 `10` 仍是前缀；
   - S4 收 1 → S1：`10111` 后缀 `1` 仍是前缀；
   - S5 收 1 → S3：命中 `10110` 后，`101101` 的后缀 `101` 可直接续上——**命中态的转移是前缀态的镜像**，这是重叠检测最容易漏的一步。
4. **`din_valid` 全局门控**：无效拍状态机原地自保持，不做状态转移。
5. **TB 技巧**：复位期间 `din_valid=0`；释放复位与灌数据之间留 `#(PERIOD/6)` 偏移，避免数据在时钟沿附近翻转。
