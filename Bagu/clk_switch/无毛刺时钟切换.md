# 无毛刺时钟切换（Glitch-Free Clock Switch）

> 对应代码：[clk_switch.v](clk_switch.v) ｜ 面试一句话：**不能拿组合 mux 直接选时钟——sel 变化可能切在高电平，砍出半个毛刺脉冲；正确做法是"先在旧时钟低电平关旧门，确认关了，再在新时钟低电平开新门"，靠下降沿采样 + 交叉反馈实现。**

## 一、为什么需要它（问题背景）

朴素写法：

```verilog
assign clk_out = sel ? clk1 : clk0;   // ✗ 有毛刺
```

sel 是异步信号，若它恰好在 clk0 **高电平期间**翻转，输出会立刻从 1 切到 clk1（此刻可能是 0）——产生一个**截断的高脉冲（runt pulse）**。宽度可能是 0.x ns 的窄毛刺，下游触发器当真了就亚稳态。

**目标**：切换动作只允许发生在时钟的**低电平**期间——关门开门都在低电平，输出永远输出完整的脉冲。

## 二、电路（就是本目录这份代码）

```
              sel=0 选 clk0，sel=1 选 clk1

sel ──────┐
!r_DFF1_Q ┴─&──► D ──[negedge clk0]──► r_DFF0_Q ──&◄── clk0 ──┐
                                                              ├──► OR ──► clk_out
!r_DFF0_Q ─┬─&──► D ──[negedge clk1]──► r_DFF1_Q ──&◄── clk1 ─┘
sel ───────┘   （注意 en0 = !sel & !r_DFF1_Q，en1 = sel & !r_DFF0_Q）
```

```verilog
assign w_DFF0_D = !r_DFF1_Q & !sel;   // 开 clk0 门：sel=0 且 clk1 门已关
assign w_DFF1_D = !r_DFF0_Q &  sel;   // 开 clk1 门：sel=1 且 clk0 门已关

always @(negedge clk0) r_DFF0_Q <= w_DFF0_D;   // 下降沿更新 → 门控信号只在 clk0 低电平变化
always @(negedge clk1) r_DFF1_Q <= w_DFF1_D;

assign clk_out = (clk0 & r_DFF0_Q) | (clk1 & r_DFF1_Q);
```

### 切换流程（sel 从 0 → 1，背熟这段）

1. sel 变 1 → `w_DFF0_D = 0`，**下一个 clk0 下降沿** `r_DFF0_Q` 清 0。此刻 clk0 正处低电平 → **旧门干净关断，无截断脉冲**；
2. `r_DFF0_Q = 0` 反馈解锁 `w_DFF1_D`，**下一个 clk1 下降沿** `r_DFF1_Q` 置 1。此刻 clk1 处低电平 → **新门在低电平打开，第一个 clk1 脉冲完整**；
3. 中间存在一小段**两门全关的死区**（输出持续为低），这是正常代价。

切换延迟 ≈ 旧时钟的低电平时间 + 新时钟的低电平时间。

## 三、背诵要点（面试照这个顺序说）

1. **为什么 negedge（下降沿）采样**：寄存器在时钟低电平更新门控信号，门的开/关永远发生在低电平，不会砍到高脉冲。
2. **交叉反馈（!对方的Q）在防什么**：保证"**先关旧门、确认关了、再开新门**"的握手顺序，杜绝两路门同时放行——两路同时过 OR 门直接短路出毛刺。
3. **死区是特性不是 bug**：切换慢一点没关系，换的是无毛刺。
4. **sel 最好也同步化**：sel 是异步的话，先在目标时钟域打两拍再用更稳（教学版常省略）。

## 四、追问应对（Q&A）

| 追问 | 回答要点 |
|------|---------|
| **当前选中的时钟停振会怎样？**（高频反手题） | 旧门的 Q 永远等不到下降沿清零，**永远切不过去——死锁**。对策：软件保证切换时两钟都在跑；或用带超时/强制关断的变体电路 |
| 两个时钟频率悬殊（100MHz vs 32KHz）？ | 死区会拉得很长（要等慢钟的低电平），切换延迟显著，系统设计要容忍 |
| 这个电路要复位吗？ | 本版本**没有复位，上电 Q 为 X**。FPGA 有 GSR/初值可救；ASIC 需要加复位端，否则 X 传播 |
| 单级采样会不会亚稳态？ | 交叉反馈信号跨了时钟域，严格设计加一级同步（两级 negedge DFF）；但反馈信号是准静态（长期稳定才变一次），MTBF 一般足够，教学版用一级 |
| 和 clock gating（ICG）什么区别？ | ICG（latch-based gating cell）是**省功耗**：让时钟不翻转；本电路是**切换**：二选一路由。都是"别在高电平乱动时钟"这一族 |
| 4 选 1 怎么扩展？ | 每路一个门控 + OR 树，使能条件改为 one-hot：`en_i = sel_i & 其它门全关`，思路不变，先全关再开新门 |
| 输出级还能优化吗？ | OR 门直接在时钟路径上，ASIC 里时钟树要平衡；可用专用 clock mux cell（库单元），把 mux 挪进 CTS 之后处理 |
