# 异步复位、同步释放（Reset Synchronizer）

> 对应代码：[async_reset.v](async_reset.v) ｜ 面试一句话：**复位拉低立即生效（异步），复位释放打两拍再放行（同步）——既要生效快，又不能让释放沿撞上时钟沿出亚稳态。**

## 一、为什么需要它（问题背景）

复位方案的两难：

| 方案 | 优点 | 缺点 |
|------|------|------|
| 纯异步复位 | 不依赖时钟，随时生效；不占数据路径 | **释放时机不可控**，若释放沿落在 clk 有效沿附近 → 违反 recovery/removal → 亚稳态或"部分触发器复位了、部分没有" |
| 纯同步复位 | 时序工具可分析、抗毛刺 | 必须有时钟才能复位；复位脉宽不够宽采不到 |

**折中：断言走异步、释放走同步**——两个优点都要。

### recovery / removal（必须会讲）

类比 setup/hold，只不过是针对**复位端**的：

- **recovery time（恢复时间）**：复位**释放**（上升沿）必须比 clk 有效沿**至少提前**的时间 → 类比 setup
- **removal time（移除时间）**：复位**断言**（下降沿）在 clk 有效沿之后还必须**保持**的时间 → 类比 hold

异步复位的问题就在于：断言不受控、释放也不受控，释放沿贴着时钟沿就违反 recovery，触发器输出亚稳态。

## 二、电路（就是本目录这份代码）

```
rst_n ──┬──────────────────────────────┐ (异步复位端)
        │                              │
clk ──► DFF[0] ──► DFF[1] ──► rst_out  │
        ▲   D 端接 1（VDD）             │
        └──────────────────────────────┘
```

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin          // 断言：异步路径，不等时钟
        rst_sync0 <= 1'b0;
        rst_sync1 <= 1'b0;
    end
    else begin                 // 释放：同步路径，打两拍
        rst_sync0 <= 1'b1;
        rst_sync1 <= rst_sync0;
    end
end
assign rst_out = rst_sync1;
```

### 两个动作分别怎么走

| 动作 | 路径 | 延迟 |
|------|------|------|
| **断言**（rst_n↓） | 走 DFF 的异步复位端，两级同时清零，`rst_out` 立即为 0 | **0 个时钟周期**，无需时钟 |
| **释放**（rst_n↑） | 走 D 端同步路径，`rst_sync0` 先变、`rst_sync1` 再变 | **2 个 posedge clk** 后 `rst_out` 才为 1 |

## 三、背诵要点（面试照这个顺序说）

1. **为什么两级、不是一级**：rst_n 释放沿如果贴近 clk 沿，第一级输出可能亚稳态；第二级隔离一拍，让 MTBF 指数级改善——和单 bit 电平同步器同一个原理。
2. **断言是异步的**：复位生效不等时钟，所以上电、时钟还没起振时也能把全芯片按住。
3. **释放延迟 2 拍是设计允许的**：释放快慢无所谓，关键是不能在不确定的时刻释放。
4. **每个时钟域要一套**：不能把 A 时钟域同步好的复位直接给 B 域用——那本身就是个跨域信号。每个 clk 域各自放一个 reset synchronizer。

## 四、追问应对（Q&A）

| 追问 | 回答要点 |
|------|---------|
| recovery/removal violation 怎么修？ | 就是本电路：异步断言 + 同步释放，释放对齐到时钟沿 |
| 复位信号扇出很大怎么办？ | 复位树：插 buffer tree / 用高驱动单元，约束 max_fanout、max_transition；同步器输出当"复位根" |
| 异步复位的缺点还有啥？ | 对**毛刺敏感**（glitch 可能被当成复位）；本电路只解决释放，不解决毛刺，毛刺要靠复位滤波（RC + Schmitt）或同步复位 |
| 上电顺序有讲究吗？ | PLL 未锁定前时钟不稳，复位要 hold 到时钟稳定（看 PLL lock 信号）再释放 |
| DFT（扫描链）时怎么办？ | 异步复位在 ATPG 测试时会被强制/旁路，扫描模式下同步器通常要 bypass——点到为止，说明知道有这回事即可 |
| 同步释放的"2 拍窗口期"电路在干嘛？ | 各触发器可能不同步复位释放？——不会：下游用的 `rst_out` 是同一个同步后的信号，同域内一起释放 |
