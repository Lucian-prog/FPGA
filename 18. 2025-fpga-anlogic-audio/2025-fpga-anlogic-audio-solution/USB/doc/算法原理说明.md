## 2. IIR数字滤波器

### 2.1 基本原理

IIR（Infinite Impulse Response，无限脉冲响应）滤波器是一种递归滤波器，其输出不仅取决于当前和过去的输入，还取决于过去的输出。

**传递函数**：

```text
        b₀ + b₁·z⁻¹ + b₂·z⁻²
H(z) = ─────────────────────────
        1 - a₁·z⁻¹ - a₂·z⁻²
```

**差分方程**：

```text
y[n] = b₀·x[n] + b₁·x[n-1] + b₂·x[n-2] + a₁·y[n-1] + a₂·y[n-2]
```

### 2.2 二阶节（Biquad）结构

本系统采用 **Direct Form I** 结构的二阶IIR滤波器：

```text
x[n] ──┬──────────────────────────────┬──▶ (+) ──▶ y[n]
       │                              │      ▲
       │                              │      │
       ▼                              ▼      │
    [z⁻¹]                          [z⁻¹]    │
       │                              │      │
       ├──▶ ×b₁ ──▶ (+)              ├──▶ ×a₁ ──┘
       │            ▲                │      
       ▼            │                ▼      
    [z⁻¹]           │             [z⁻¹]     
       │            │                │      
       └──▶ ×b₂ ────┘                └──▶ ×a₂ ──▶ (+)
```

### 2.3 级联设计

为实现更陡峭的滤波器响应，本系统采用**两个二阶节级联**，形成四阶滤波器：

```text
H_total(z) = H₁(z) × H₂(z)
```

**优势**：

- 每级独立稳定，系数敏感度低
- 四阶滤波器滚降约 24 dB/octave
- 便于分级调试

### 2.4 系统中的滤波器配置

| 滤波器 | 中心频率/通带 | 应用场景 | 系数特征 |
|--------|-------------|---------|---------|
| 窄带通话 | 200-4000 Hz | 电信标准语音 | 带通，Q值中等 |
| 低音增强 | 300 Hz | 低音EQ | 峰值滤波，低Q |
| 人声增强 | 2000 Hz | 人声清晰度 | 峰值滤波，中Q |
| 氛围增强 | 4000 Hz | 高频空气感 | 峰值滤波，中Q |

### 2.5 定点化处理

为适应FPGA实现，所有系数经过定点化处理：

- **系数定标**：原始系数 × 1024，转换为整数
- **中间累积**：使用41位宽度防止溢出
- **乘法结果**：57位（41位 × 16位）
- **除法实现**：通过移位操作（÷1024 = >>10）

## 3. AGC自动增益控制

### 3.1 基本原理

AGC（Automatic Gain Control）的目标是使输出信号幅度保持在目标范围内，无论输入信号幅度如何变化。

**基本公式**：

```text
y[n] = x[n] × amp[n]

                    target - |y[n]|_avg
amp[n+1] = amp[n] + ─────────────────────
                            K
```

其中：

- `amp[n]` 是当前增益系数
- `target` 是目标幅度
- `|y[n]|_avg` 是输出信号的平均幅度
- `K` 是调整速度因子

### 3.2 双时间常数设计

本系统采用**双时间常数**架构，这是专业音频设备的标准做法：

```text
                    输入信号
                       │
                       ▼
                ┌──────────────┐
                │   乘法器      │◀─── amp（增益系数）
                │  y = x × amp │
                └──────┬───────┘
                       │
                       ▼
                   取绝对值
                       │
          ┌────────────┴────────────┐
          │                         │
          ▼                         ▼
   ┌─────────────┐          ┌─────────────┐
   │  长时累加器  │          │  短时累加器  │
   │  1024点窗口  │          │   32点窗口   │
   │   ≈21ms     │          │   ≈0.67ms   │
   └──────┬──────┘          └──────┬──────┘
          │                        │
          ▼                        ▼
      long_ave                 short_ave
          │                        │
          ▼                        ▼
   ┌─────────────┐          ┌─────────────┐
   │ target-long │          │ target-short│
   │   = ldd     │          │   = sdd     │
   └──────┬──────┘          └──────┬──────┘
          │                        │
          │ ÷4 (慢调)              │ ÷16 (快调)
          │                        │
          └─────────┬──────────────┘
                    │
                    ▼
              amp 更新
         (带上下限钳位)
```

### 3.3 时间常数的作用

| 时间常数 | 窗口长度 | 响应时间 | 作用 |
|---------|---------|---------|------|
| **长时** | 1024点 | ≈21ms | 跟踪语句级别的平均音量，保持整体稳定 |
| **短时** | 32点 | ≈0.67ms | 快速响应突发大音量（如咳嗽），防止削波 |

### 3.4 增益钳位

为防止极端情况，增益系数限制在合理范围：

```text
2048 ≤ amp ≤ 24576

换算为倍数：0.25× ≤ gain ≤ 3×
```

**作用**：

- 下限防止静音时过度放大噪声
- 上限防止小信号时增益失控

## 4. 互相关声源定位

### 4.1 基本原理

声源定位基于**TDOA（Time Difference of Arrival，到达时间差）**原理：

当声源位于不同方向时，声波到达各麦克风的时间不同。通过测量这个时间差，可以推算声源方向。

**几何关系**：

```text
        d × cos(θ)
Δt = ──────────────
           c
```

其中：

- `Δt` 是时间差
- `d` 是麦克风间距
- `θ` 是声源角度
- `c` 是声速（约340 m/s）

### 4.2 互相关函数

时间差通过**互相关函数**求取：

```text
         N-1
R_xy[τ] = Σ  x[n] × y[n+τ]
         n=0
```

- `x[n]` 和 `y[n]` 是两路麦克风信号
- `τ` 是延迟（以采样点为单位）
- 使 `R_xy[τ]` 最大的 `τ` 值对应真实时间差

```text
麦克风1信号: ─────╱╲╱╲────────────
                  ↑
              声音到达

麦克风2信号: ──────────╱╲╱╲───────
                       ↑
                   延迟 τ 后到达

互相关结果:
R[τ]
  │
  │        ╱╲
  │       ╱  ╲
  │      ╱    ╲
  │─────╱──────╲─────▶ τ
        ↑
      峰值位置 = 时间差
```

### 4.3 搜索范围

本系统搜索范围为 ±32 个采样点：

- 采样率：48 kHz → 每点 ≈ 20.8 μs
- 声程差：20.8 μs × 340 m/s ≈ 7 mm/点
- 总搜索范围：±32 × 7 mm ≈ ±224 mm

### 4.4 多麦克风对组合

使用三组麦克风对计算互相关，获取更准确的方位信息：

```text
              mic_1 (参考)
                 ●
                /|\
               / | \
              /  |  \
         mic_2   |   mic_3
           ●     |     ●
                 |
               mic_4
                 ●

xcorr1: mic_1 vs mic_2  → 方位分量1
xcorr2: mic_1 vs mic_3  → 方位分量2
xcorr3: mic_1 vs mic_4  → 方位分量3
```

### 4.5 结果显示

互相关峰值位置映射到LED灯环，直观显示声源方向：

- `sequence_num = 32` → 正前方（无延迟）
- `sequence_num < 32` → 声源偏左
- `sequence_num > 32` → 声源偏右

## 5. 波束成形

### 5.1 基本原理

波束成形（Beamforming）利用多麦克风阵列的空间信息，增强特定方向的信号，抑制其他方向的噪声。

**延时-求和波束成形（Delay-and-Sum）**：

```text
        M
y[n] =  Σ  wᵢ × xᵢ[n - τᵢ]
       i=1
```

其中：

- `M` 是麦克风数量
- `wᵢ` 是权重系数
- `τᵢ` 是补偿延迟
- `xᵢ[n]` 是第i路麦克风信号

### 5.2 工作原理图

```text
目标方向的声波
       ↓  ↓  ↓
    ●  ●  ●  ●  ●  ●  ●   ← 麦克风阵列
    │  │  │  │  │  │  │
    ▼  ▼  ▼  ▼  ▼  ▼  ▼
  [τ₁][τ₂][τ₃][τ₄][τ₅][τ₆][τ₇]  ← 延迟补偿
    │  │  │  │  │  │  │
    └──┴──┴──┬──┴──┴──┘
             ▼
           求和 Σ
             │
             ▼
         增强输出
```

### 5.3 7路麦克风到立体声

本系统将7路麦克风信号处理为左右两个声道：

| 声道 | 使用的麦克风 | 说明 |
|------|------------|------|
| 左声道 | mic_1, mic_3, mic_5 | 阵列左侧 |
| 右声道 | mic_0, mic_2, mic_4, mic_6 | 阵列右侧 |

### 5.4 波束成形的优势

1. **定向拾音**：增强目标方向的语音
2. **噪声抑制**：抑制非目标方向的干扰
3. **远场拾音**：扩大有效拾音距离
4. **抗混响**：减少房间反射的影响

## 6. USB音频协议

### 6.1 USB Audio Class

本系统实现 **USB Audio Class 1.0** 规范，作为标准USB麦克风设备：

| 参数 | 规格 |
|------|------|
| USB速度 | Full-Speed (12 Mbps) |
| 音频格式 | PCM |
| 采样率 | 48 kHz |
| 位深度 | 16 bit |
| 声道数 | 2（立体声） |
| 驱动 | 免驱动（UAC标准） |

### 6.2 同步机制

USB音频采用**同步传输（Isochronous Transfer）**：

- 每1ms一个USB帧
- 每帧传输48个采样点（48kHz/1000Hz = 48）
- 每个采样点4字节（左16bit + 右16bit）
- 每帧数据量：48 × 4 = 192 字节

### 6.3 缓冲设计

为平滑USB传输的突发特性，系统使用双缓冲：

```text
麦克风采集 (48kHz稳定)
       │
       ▼
  ┌─────────┐
  │ 写缓冲  │ ← 持续写入
  └────┬────┘
       │
       ▼
  ┌─────────┐
  │ 读缓冲  │ → USB突发读取
  └─────────┘
       │
       ▼
  USB传输 (每1ms突发)
```

## 7. I2S音频接口

### 7.1 I2S协议简介

I2S（Inter-IC Sound）是飞利浦制定的数字音频传输标准，用于芯片间的音频数据传输。

**三线结构**：

- **BCLK**（Bit Clock）：位时钟
- **LRCK/WS**（Left-Right Clock / Word Select）：帧时钟，指示左右声道
- **DATA**：串行数据线

### 7.2 时序关系

```text
LRCK:   ────────┐                     ┌────────
                │      左声道          │    右声道
                └─────────────────────┘

BCLK:   ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
         └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘

DATA:   ──X D15 X D14 X D13 X ... X D1 X D0 X───
            MSB                         LSB
```

### 7.3 本系统I2S配置

**ES8388 编解码器配置**：

| 时钟 | 频率 | 计算 |
|------|------|------|
| MCLK | 12.288 MHz | 256 × 48kHz |
| BCLK | 3.072 MHz | 64 × 48kHz |
| LRCK | 48 kHz | 采样率 |

**时钟分频关系**：

```text
MCLK ──(÷4)──▶ BCLK ──(÷64)──▶ LRCK
```

### 7.4 麦克风I2S接口

MEMS麦克风采用I2S输出，每路数据线承载两个麦克风（左右声道时分复用）：

```text
mic_data[0]: mic_0(R) + mic_1(L)
mic_data[1]: mic_2(R) + mic_3(L)
mic_data[2]: mic_4(R) + mic_5(L)
mic_data[3]: mic_6(R) + (unused)
```
